# Cake Stories storefront

## Goal
Recreate the reference cake-shopping experience at `/` for Cake Stories, using original branding, copy, and imagery rather than copying IGP assets or marks.

## Build
- Create a compact storefront header with delivery location, search, account, wishlist, and cart controls.
- Add a cake category rail, an image-led promotional banner, trust highlights, and filter/sort controls.
- Build a responsive product grid with realistic cake names, prices, ratings, delivery badges, favorites, and working category/search/filter interactions.
- Add supporting category discovery and service reassurance sections so the page feels like a complete cake catalogue.
- Define a warm confectionery design system and responsive behavior for desktop and mobile.
- Add page-specific search and social metadata for cakestories.in.

## Assets
- Generate original Cake Stories cake photography for the banner and product catalogue.

## Validation
- Check the storefront at desktop and mobile sizes, exercise key controls, and confirm there are no visible or runtime errors.
